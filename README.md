# MAD_project
The UrbanBazaar Online Shopping System is an Android-based mobile application designed to ease the e-commerce experience by prioritizing user convenience and security. This project addresses common points in online shopping, such as cluttered interfaces, inefficient navigation and lack of tailored recommendations. Built using Kotlin, Android Studio and Jetpack Compose for the frontend, and Firebase for backend services (authentication, real-time database and cloud storage), Urban Bazaar offers a seamless shopping journey. Key features include a filterable product catalog, wish list and cart management, secure pay slip generation. UrbanBazaar is tailored for busy professionals, students, and families, aiming to save time and simplify online shopping. This project demonstrates the potential of user-centric design and modern mobile technologies to transform digital commerce.
